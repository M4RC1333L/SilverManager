# Silver Manager - Sistema de Gestão de Joalheria

### 🚩 Status do Projeto
Em desenvolvimento 🛠️

### 🎯 Objetivo do Software
O Silver Manager tem como objetivo facilitar o controle de vendas, estoque e cadastro de clientes para pequenos e médios varejistas de joias, garantindo que o fluxo de caixa e o inventário estejam sempre sincronizados de forma automatizada.

### 🚀 Tecnologias Aplicadas
* **Linguagem:** Java (JDK 17+)
* **Interface Gráfica:** Java Swing
* **IDE:** NetBeans
* **Banco de Dados:** MySQL
* **Versionamento:** Git & GitHub

### 🛠️ Funcionalidades (Requisitos)
* [x] Cadastro e Edição de Clientes.
* [x] Gestão de Inventário (Cadastro de Produtos com Código de Barras).
* [x] Ponto de Venda (PDV) com carrinho de compras.
* [x] Baixa automática de estoque após finalização da venda.
* [x] Persistência de dados em banco de dados relacional.
